Seja bem-vindo(a) à Experiência Prática III da disciplina de Desenvolvimento front-end. Esta jornada representa um momento fundamental para conectar os conhecimentos teóricos adquiridos em sala de aula com a aplicação prática.

Através desta experiência, será possível aprofundar a compreensão sobre como o JavaScript pode transformar estruturas estáticas em interfaces altamente responsivas e funcionais, simulando o comportamento de sistemas reais no mercado de trabalho.

Objetivos da Experiência Prática
Ao final desta experiência prática, espera-se que o(a) estudante seja capaz de:

- Compreender como usar JavaScript para tornar páginas web interativas;
- Manipular elementos da página (DOM) para alterar conteúdo e estilo dinamicamente;
- Implementar e controlar eventos do utilizador (cliques, formulários, etc.);
- Utilizar armazenamento local (localStorage) para guardar e recuperar dados;
- Integrar funcionalidades básicas de um framework JavaScript;
- Desenvolver pequenas funcionalidades que simulem o comportamento de uma aplicação real;
- Organizar o código de forma clara e reutilizável;
- Testar e corrigir erros no funcionamento da aplicação.

O percurso desta experiência prática foi cuidadosamente estruturado para guiar o desenvolvimento técnico passo a passo, com o intuito de capacitá-lo(a) na implementação de lógicas avançadas de programação front-end.
